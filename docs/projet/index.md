# Le projet

L'équipe **Unimakers** (MakerSpace Amiens) participe à la **Coupe de France de Robotique 2027**, thème « The Legend of Camelot ».

## Nos robots

- Un **robot principal**, qui réalise les actions de jeu sur la table : [Le robot principal](../robot-principal/index.md).
- Des **PAMI**, petits robots autonomes qui partent de l'écurie en fin de match : [Les PAMI](../pami/index.md).
